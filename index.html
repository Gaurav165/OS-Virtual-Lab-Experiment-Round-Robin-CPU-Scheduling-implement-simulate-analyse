Aim & theory

Implement the Round Robin algorithm and analyse its performance for different time quanta.

  • Round Robin is a preemptive algorithm designed for time-sharing systems.
  • Every process gets a fixed slice of CPU time called the time quantum (q).
  • The ready queue works as FIFO: the process at the front is dispatched.
  • If a process does not finish within q, it is preempted and sent to the back of the queue.
  • No process waits more than (n−1)×q units for its next turn — so there is no starvation.
TAT = CT − ATTurnaround time
WT = TAT − BTWaiting time
RT = First start − ATResponse time
Util = Busy ÷ TotalCPU utilisation

Algorithm

The steps this lab implements.

1. Sort processes by arrival time; queue = []
2. Add all processes with AT ≤ time to queue
3. Pop the front process p
4. run  = min(quantum, p.remaining)
   time += run;  p.remaining -= run
5. Add processes that arrived while p ran
6. if p.remaining > 0 → push p to back
   else CT[p] = time
7. Repeat until all finish
   (if queue is empty, jump to next arrival)
